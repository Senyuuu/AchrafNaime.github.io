Manag’Eat, application de gestion de restauration

Février à mai 2026, ENSEEIHT, équipe de 6

Application de gestion de restauration centralisée, développée en Java par une équipe Scrum de six personnes.

  • Architecture et backend. Conception MVC en Java Swing, persistance des données en JSON avec Gson, et design pattern State pour gérer le cycle de vie des tables.
  • Module RH et données. Algorithmes de suivi des ressources humaines (turnover, absentéisme) et croisement du chiffre d’affaires avec la productivité horaire.
  • Travail en équipe. Méthode agile avec Jira, gestion Git rigoureuse pour éviter les conflits, et revues de code.

Technologies Java, Swing, Gson, JSON, Git, Jira, Scrum

Thermomètre infrarouge intelligent

Mai 2024, projet TIPE, classe préparatoire

Conception et optimisation d’un thermomètre dont la mesure s’adapte aux influences de l’environnement.

  • Électronique. Montage et acquisition des données avec une carte Arduino Uno, un capteur infrarouge MLX90614 et un capteur DHT22.
  • Modélisation. Modèle physique avec une correction exponentielle de l’humidité pour compenser les perturbations.
  • Analyse de données. Scripts Python (NumPy, Matplotlib) pour automatiser le calcul des erreurs et tracer les mesures corrigées.

Technologies Arduino, Python, NumPy, Matplotlib
